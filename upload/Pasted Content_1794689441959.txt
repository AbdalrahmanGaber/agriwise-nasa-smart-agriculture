## FEATURE 1 — SMART PLANTING TIME ADVISOR

<badge>Priority 1 — Highest</badge>

Create a dedicated tool named:

**Smart Planting Time Advisor**

Main question:

**Plant Now or Wait?**

Its purpose is to help farmers identify the most suitable planting season and planting period for a selected crop and geographical location.

### 1. User Interface

Create a dedicated section containing:

- Crop name text input.
- Autocomplete suggestions for supported crops.
- Farm location selection using the existing location map.
- Optional crop variety input.
- Analyze Planting Time button.

The user should be able to type crop names directly, including:

- Sugarcane.
- Wheat.
- Maize.
- Rice.
- Tomato.
- Potato.
- Onion.

Do not restrict the user to a dropdown.

### 2. Agricultural Knowledge Database

Create or improve a structured crop requirements database.

For each supported crop, include documented information about:

- Scientific name.
- Suitable planting seasons.
- Recommended planting months.
- Optimum temperature range.
- Minimum and maximum temperature tolerance, when documented.
- Rainfall and water requirements.
- Relative humidity requirements, when available.
- Solar radiation requirements, when available.
- Growth duration.
- Agricultural references.

Use reliable sources, including:

- FAO publications.
- Egyptian agricultural extension publications.
- Recognized scientific agricultural references.

Every important agricultural threshold must have a traceable source.

Do not invent missing values.

If a crop is unsupported, clearly explain that verified requirements are unavailable.

### 3. NASA POWER Climate Analysis

Retrieve available climate data for the selected coordinates using the existing NASA POWER integration.

Analyze the following parameters:

| Parameter | NASA POWER variable |
|---|---|
| Average temperature | T2M |
| Maximum temperature | T2M_MAX |
| Minimum temperature | T2M_MIN |
| Precipitation | PRECTOTCORR |
| Relative humidity | RH2M |
| Solar radiation | ALLSKY_SFC_SW_DWN |
| Wind speed | WS10M |

Use multiple years of historical climate data to identify local seasonal patterns.

Do not use only the latest 365 days to determine normal planting seasons.

Analyze:

- Historical monthly temperature patterns.
- Maximum and minimum temperature.
- Rainfall distribution.
- Solar radiation.
- Relative humidity.
- Possible heat stress.
- Possible cold stress.
- Seasonal climate suitability.

Respect the temporal resolution and units of each NASA POWER variable.

Do not treat historical climate data as real-time weather.

### 4. Planting Season Decision

Determine whether the selected crop is normally suitable for:

- Summer planting.
- Winter planting.
- Spring planting.
- Autumn planting.
- Multiple planting seasons.

The recommendation must depend on:

- Selected crop.
- Selected geographical location.
- Documented crop requirements.
- Historical climate patterns.

Do not hardcode a planting season based only on the crop name.

### 5. Plant Now or Wait Decision

Display one of three results:

- PLANT NOW.
- WAIT.
- NOT RECOMMENDED.

Explain the decision using documented crop requirements and available environmental data.

For each result, display:

- Recommended planting season.
- Best planting month or planting window.
- Alternative suitable months.
- Available current weather information, if connected.
- Crop temperature requirements.
- Temperature suitability.
- Rainfall suitability.
- Potential heat or cold stress.
- Scientific explanation.

Important:

A historical climate average cannot independently confirm that today's weather is suitable for planting.

If actual current observations or forecast data are unavailable, clearly label the result as a historical seasonal recommendation rather than a real-time planting decision.

Do not claim NASA POWER provides a weather forecast.

If necessary, use a separate reliable weather API for current conditions and forecasts, and clearly identify its source.

### 6. Annual Planting Suitability Chart

Create an interactive 12-month chart.

For each month, display:

- Suitable.
- Partially suitable.
- Unsuitable.
- Data unavailable.

Use:

- Green for suitable.
- Yellow for partially suitable.
- Red for unsuitable.
- Neutral styling for unavailable data.

When a farmer selects a month, show:

- Historical climate conditions.
- Documented crop requirements.
- Explanation of the suitability result.

Do not generate arbitrary monthly scores.

### 7. Results Dashboard

Display:

- Plant Now or Wait decision.
- Recommended planting season.
- Best planting month.
- Temperature suitability.
- Rainfall suitability.
- Historical climate chart.
- Monthly suitability chart.
- Scientific explanation.
- Data sources.

Use simple farmer-friendly explanations in Arabic while retaining relevant English scientific terminology.
